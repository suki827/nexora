# Nexora 管理工作台

`src/Nexora.Web` 是 Blazor Razor 类库，页面、样式和浏览器上传代码放在这里；`src/Nexora.Api` 同时提供页面与 `/api` 接口。同源访问沿用现有 Identity Cookie 和 CSRF。**在 Visual Studio 中把 `Nexora.Api` 设为启动项目**；不需要单独启动 `Nexora.Web`。访问 API 启动地址的 `/`，会进入媒体资源页；未登录时会跳转到 `/login`。

运行前仍需按 [媒体上传与分析说明](media-pipeline.md) 配置 PostgreSQL、媒体目录和 Worker。页面不会自动创建数据库或运行迁移。

已提供的页面：

- `/login`：登录和注册。
- `/assets`：创建、分页查看媒体资源，切换显示已归档资源。
- `/assets/{id}`：修改资源、上传原始文件、查看文件与元数据、音频波形，以及从已就绪文件进入任务创建。
- `/tasks`：创建技术元数据分析任务和查看分页列表。
- `/tasks/{id}`：查看输入、执行记录、结果、产物和请求取消；未结束时自动刷新状态。

上传采用浏览器对现有接口发 8 MiB 分片。上传会话 ID 保存在浏览器本地存储中；选择同一文件再次点击上传时可查询已上传分片并继续。服务端仍会校验分片和文件内容。音频波形由浏览器从现有峰值 JSON 绘制。技术元数据任务需要启动 `Nexora.Worker`；源文件处理完成后，任务结果会出现在详情页。

管理工作台是面向登录用户管理自己资源的界面，目前没有跨用户的系统管理员角色或后台接口。列表页和资源文件页已分页；资源详情当前展示前 100 个文件，更多文件的翻页界面可后续补充。
